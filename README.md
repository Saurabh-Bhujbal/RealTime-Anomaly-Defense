# Real-Time Dynamic Anomaly Detection and Self-Purifying Defensive Layers for Autonomous Visual Systems

## Project Overview

This project develops a multi-layer defensive framework for detecting and mitigating adversarial manipulation of visual deep learning systems.

## Dataset

The project uses the MNIST handwritten digit dataset supplied in IDX format.

## Planned Components

1. MNIST dataset loader
2. Baseline CNN classifier
3. FGSM adversarial attack
4. PGD adversarial attack
5. Dynamic anomaly detection
6. Self-purification
7. DIP-inspired purification
8. Randomized neural network defense
9. Gradient-diversity-inspired regularization
10. Combined defense pipeline
11. Robustness evaluation
12. Latency evaluation
13. Streamlit visualization dashboard
